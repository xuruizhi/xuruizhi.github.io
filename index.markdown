AI 辅助研发不是「把 ChatGPT 接进 IDE」这么简单。当模型开始负责写代码、写测试、做评审，
工程师的活儿就变成了另一件事：**定义问题、设计约束、验证结果**。

这个博客沿着三条线写：

- **AI 辅助研发** —— 日常编码 / 重构 / Code Review / 单测生成中，AI 究竟在哪里省了事、在哪里挖了坑；
- **Agent 工程** —— 工具调用、MCP、RAG、编排与上下文管理，怎样把模型从对话框做成系统；
- **AI 质量保障** —— 被测对象变成概率性的模型之后，测试策略、评测集与回归该怎么做。

我的背景是测试工程 —— 所以这里的文章尽量对「**怎么证明它是对的**」有交代，
而不只是「我跑通了一个 demo」。
